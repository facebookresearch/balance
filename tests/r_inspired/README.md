# R-inspired tests and reference material: mixed licenses

This is a **mixed-license test folder**, not a uniformly MIT-licensed fixture collection. The newly written Python and R test harnesses retain their Meta MIT source headers. Reproduced upstream fixture values, source notices and reference material are attributed component by component in each fixture bank's README and manifest.

## Self-contained test diffs

Each test module has its own bank under `fixtures/<group>/`. The test, required inputs/expectations, provenance, declared license notices and changelog entry belong to the same review diff. Related tests may reuse the same upstream data, but each bank keeps only the expectations that its own tests consume. There is no shared first-diff numerical fixture bank.

`test_cbps_r_comparison.py` owns the archived `fixtures/cbps/` bank and its local loader. The original CSV and R capture script are test-only, no longer production package resources or a `balance.datasets.load_data` option. Its README/manifest record CBPS 0.23 and R 3.6.1 from the archived script, distinguish that from the read current package declaration, and mark the bank `capture_only` rather than silently regenerating historical results with current R packages.

These are factual source declarations, not a blanket license assignment to every file. Source notices/description files and applicable declared license texts accompany each bank. Original source hashes are separate from assembled notice hashes; notice normalization removes only trailing spaces/tabs and extra final blank lines.

## Exact-byte integrity across checkouts

Fixture-bank manifests hash the stored file bytes, including line endings. The scoped `fixtures/.gitattributes` rule disables Git text conversion for these frozen data and notice files, so Windows checkouts preserve the same bytes as other platforms. It does not change the files, recorded digests, or numerical expectations. Do not regenerate digests or normalize content merely to accommodate checkout conversion.

The ordinary test suite includes `test_r_fixture_checkout.py`. It checks every manifest resource through a temporary Git checkout with `core.autocrlf=true` and `false`, and confirms that originally CRLF bytes are also preserved. The checkout-specific regression skips when Git itself is unavailable; GitHub's checkout jobs have Git, and the existing fixture-integrity and numerical tests remain unconditional.

## Numerical scope and provenance

Frozen expectations were independently executed in R, not generated by balance. Full probability, weight and prediction vectors are compared where definitions match. Extra scale/replay/threshold/partition guards are labelled separately; different survey uncertainty, frequency/reliability variance and binary SMD conventions are not presented as raw numerical equivalence.

The captures used R 4.6.1 and the recorded source-package versions. Build-only legacy declarations/allocation aliases are documented; no historical-runtime or patched-numerical-source claim is made. Each bank records its original sources, versions, runtime/configuration and source attribution. Python CI reads the bank without R.

`generators/regenerate_r_fixtures.py` regenerates only selected/available banks from their own manifests. It fails on missing dependencies, wrong versions, altered folds or stale output directories. For a single bank:

```sh
fbpython generators/regenerate_r_fixtures.py \
  --fbsource=/path/to/fbsource --outdir=/path/to/new-empty-output --group=weighting
```
